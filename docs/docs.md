# Salesforce Page Layouts

## What is a Page Layout?

A Page Layout controls how fields, sections, buttons and related
lists are arranged and presented when users view or edit a record.

# Important Concepts

Page Layout controls:

- Field placement
- Field order
- Sections
- Required fields
- Read-only fields
- Buttons
- Related Lists

---

# Page Layout vs Validation Rule

Page Layout:

Controls how information is displayed and edited.

Validation Rule:

Controls whether entered information is valid.
