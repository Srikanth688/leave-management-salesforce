# Salesforce Tabs

## What is a Tab?

A Salesforce Tab provides users with a way to access an object
and its records through the Salesforce interface.

---

# Tabs Created

The following custom tabs were created:

1. Employee
2. Leave Request
3. Leave Balance
4. Holiday

---

# Purpose

Tabs make the objects easily accessible to users.

For example:

Employee Tab
   ↓
Employee Records

Leave Request Tab
   ↓
Leave Request Records
