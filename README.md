# 🏢 Leave Management System

A Salesforce-based Leave Management System built while learning
Salesforce development from beginner to industry-level concepts.

The project is being developed step-by-step. Each Salesforce
concept is learned first and then implemented in the project.

---

## 🎯 Project Objective

The Leave Management System is designed to manage:

- Employee information
- Employee leave requests
- Leave balances
- Company holidays
- Leave approval process
- HR and manager operations

---

## 🛠️ Technology

- Salesforce
- Salesforce Lightning Platform
- Salesforce Flow
- SOQL
- Apex
- Lightning Web Components (LWC)
- Salesforce CLI
- Git
- GitHub

---

# 🏗️ Salesforce Data Model

The project currently contains four main custom objects:

### 1. Employee

Stores employee information.

### 2. Leave Request

Stores employee leave applications.

### 3. Leave Balance

Stores employee leave balances.

### 4. Holiday

Stores company holidays.

---

# 🔗 Relationships

The current relationship structure is:

Employee
│
├── Leave Requests
│
└── Leave Balance

Holiday is maintained separately for company holidays.

---

# 📖 Learning Approach

This project follows:

**Learn → Build → Test → Document → Commit**

For every Salesforce concept:

1. Understand the concept
2. Implement it in the Leave Management System
3. Test the implementation
4. Take screenshots
5. Write learning notes
6. Commit the work to GitHub
